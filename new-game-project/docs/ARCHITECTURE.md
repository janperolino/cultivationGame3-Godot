# Native architecture contract

2026-10-25. Planned boundaries; no empty framework or port is implemented by this document. [Build plan](../../plan.md).

## Simulation and coordinates

Use GDScript initially. A host-owned Simulation service contains actor/attack/terrain state and explicit commands; a local solo adapter calls the same authority used by a network host. Nodes present state rather than author damage. Inject seeded RNG and tick/time; keep input polling, wall-clock, rendering, audio, file access and transport outside rules. Godot physics is not assumed deterministic across machines; use authoritative snapshots, never peer lockstep.

One unit is one metre, time seconds; +Y is altitude, browser horizontal (x,y) maps to Godot (x,z), browser altitude maps to Godot Y. Document headings/handedness with axis fixtures. Ground-relative clearance and world altitude are separate values. Host runs 60 fixed ticks/s; all cooldowns, telegraphs, revive and stale-command decisions use this clock. Presentation interpolates fixed states. Clamp catch-up to a bounded number of steps (initial proposal 4/frame), record overload/time debt and refuse unlimited catch-up; do not silently use render delta for combat. Profile headless and rendered hosts.

Content definitions have stable IDs, bounded fields and validated cross-references before constructing mutable actors. Immutable host loadouts/team assignments cannot be changed through client packets. Runtime entity IDs, spawn generations, session IDs and encounter epochs distinguish reuse and reset. Ordered event IDs drive deduplicated transient presentation; effects never apply damage. Record enough authoritative state/RNG for later save/replay rather than assuming display snapshots are restorable saves.

## Terrain, collision and aiming

N1 must decide the canonical sampling contract explicitly: browser has 128x128 four-metre cell-center heights, native has 129x129 vertex depths/bilinear samples. Recommended native basis: vertex field, with an explicit versioned conversion for reference fixtures only. Do not call it bitwise terrain parity or silently load browser saves. Use a bounded 512m region for parity; later regions carry stable IDs.

One canonical height/depth/cover state drives movement, projectile tests, aiming, render meshes and collision updates. Dirty revisions/chunk borders include all shared vertices. Bilinear sampling currently differs from the mesh triangle surface: choose matching triangulated sampling or change surface construction and test both diagonal halves. Jolt shapes are derived caches; asynchronous rebuilds must not create a tick where rules allow attacks through stale cover. Keep gameplay queries on canonical data until collider revision matches. Restrict expensive collision rebuilds to dirty chunks and measure stalls.

Cover has material, height, partial durability and destroyed state; scars cap at 12m for parity. Swept actor/projectile/volume tests prevent tunnelling at dash/projectile speeds; cover removal and crater shape affect flight clearance, interception and aim in the same tick. Define grounded/sliding response separately from flying clearance. Do not equate starter decorative buildings/trees with physical cover or add arbitrary mesh fracture.

Aim projects the cursor ray onto canonical ground or valid actor hit space, including altitude. Lock and damage share hostile/ally predicates. Ground range is not screen distance. Committed attacks capture source/heading/altitude at release; telegraphs reflect actual hit volume and windup. Clamp out-of-bounds/range intent on the host. Test ridges, crater edges, behind-cover targets, elevated allies and camera zoom extremes.

## Input, camera and UI

Replace hardcoded polling with named InputMap actions and rebinding. Initial parity: WASD camera-relative horizontal flight, F/G altitude, Shift qi-cost dash, click/1 primary, Q/2 middle, E/3 Falling Heaven, R held revive, T/middle lock, wheel zoom. Fixed camera basis determines command world direction. Normalize diagonals. Neutralize input on focus loss, menu opening and disconnect; clear held one-shots and require fresh presses after recovery. Solo pause may stop local authority; a co-op menu cannot pause only one player's combat clock.

Retain elevated orthographic follow and adjustable zoom. Optional cinematic framing, shake, hit-stop and flash are presentation settings; never slow network authority. Respect reduced motion, offer brightness/text scale and shape-coded telegraphs. HUD shows health/qi/ward, altitude/clearance, host-defined slots/cooldowns, ally/defeat/revive, encounter state, connection/snapshot progress and explicit retry. Occlusion fades roofs/foliage without hiding collision or enemies. Desktop window/fullscreen, resolution/UI scale and remapping persist as settings later; controller support is deferred pending scope.

## Authority, networking and recovery

Assess Godot ENetMultiplayerPeer for direct native host/client sessions in N3; it is a candidate, not already integrated. Compare measured packet sizes, reliable/unreliable channel behavior, malformed input handling, disconnect and export operation before selecting it. No HTTP polling port. Use explicit serialized bounded schemas and authority checks even if Godot RPC helpers are used. Never accept arbitrary client scene spawning, file paths, resources or method names.

Authority maps authenticated session peers to owned actors; peer IDs alone are not durable identity. Validate finite vectors, magnitude/range, sequence/tick windows, rate/queue limits, equipment, team, health, qi/cooldown and target legality. Host owns enemies, damage, terrain, encounter transitions and later rewards. Clients predict only bounded local movement/clearance, reconcile against acknowledged input and interpolate remote actors. Never predict health grants or authoritative destruction. Keep effect speculation cancellable. Heavenly Step uses the shared clock; personal movement/perception effects need validated tuning, no local enemy time dilation.

Initial channel proposal: unreliable sequenced latest movement/state; separate reliable ordered discrete cast/dodge/retry actions and lifecycle; bounded reliable paged join/terrain transfers. Avoid snapshot head-of-line blocking live movement. Every action has session, connection generation, encounter epoch, monotonic ID and fixed expiry; deduplicate outcomes, reject conflicting duplicates, bound queue/history, acknowledge attempted/expired versus successful. New motion cannot erase discrete actions. Retry deadlines cannot extend intent. Held revive is fresh continuous intent, not a reliable replayable action. Begin with browser limits as test fixtures (16 pending/32 recent, one action consumed per tick, 250ms neutral cutoff); adjust only with evidence and documented protocol changes.

Join gates input until an atomically validated baseline includes actors, content display IDs, encounter state and full terrain revision. Ordered bounded deltas detect gaps and resnapshot. Checksums verify reconstructed canonical terrain, not render meshes. Never partially expose malformed snapshots. Relevance/quantization are later optimizations only after correctness and measured bandwidth.

Prototype recovery proposal retains a 5s lease plus 30s reservation for the same running host; document/test actual native timing before acceptance. Disconnected enrolled actors remain vulnerable with neutral input; ordinary cooldown/qi regeneration may continue, but reconnect grants nothing. Recovery rotates connection generation, clears outbox/prediction/effects and requires a fresh snapshot. Old session/epoch packets cannot affect new actors or attempts. Explicit Leave releases control without erasing encounter enrollment. Expiry requires explicit fresh join. Host exit/crash ends the in-memory session before persistence exists; no host migration. Native player-host departure differs from Node's independent server process and must be shown clearly. Loopback first, controlled LAN later; internet NAT, relay, encryption/identity and abuse boundaries require a separate assessed deployment gate. No UPnP/firewall/public exposure by default.

## Enemies, teams and encounters

Host AI uses stable IDs, bounded perception/target ties, altitude/cover-aware flight and committed telegraphs/recovery. Begin with three skirmishers, validate six; ground navmesh and arbitrary mazes are separate scope. Equal defined teams protect allied health and exclude hostile locks; terrain consequences remain shared. Undefined team sparring is an explicit diagnostic mode, not campaign PvP consent.

State machine: waiting for first participant, active, returning, completed, defeated. Only enrolled seats count toward party wipe; enrollment persists through disconnect/Leave. Victory requires all enemies defeated. Leash cancels attacks and returns/resets enemies only, not player resources; bounded fallback avoids deadlock. Browser reference: 120m 3D anchor leash, 3s disengagement, 8s return fallback. Retry after victory/wipe restores authored player/enemy profiles, clears attacks and pending inputs, increments encounter epoch, preserves scars/credentials. Living-ally revive follows [approved prototype rule](MIGRATION.md). Revive, retry and network recovery are distinct transitions. Guardian comes after these rules pass; no rewards until transactions exist.

## Persistence and delivery boundaries

Later save service stores versioned settings, character and host world separately in `user://`, with stable region/entity IDs, terrain/cover deltas, quests, sect restoration, contributions and RNG/state needed for continuation. Use temp write, flush/validate, recoverable replace, previous-good backup, checksums and explicit migrations. Corruption/incompatibility must preserve original files. Commit rewards and spending idempotently with transaction IDs; reconnect cannot award again. Character portability/world ownership remain decisions before N7; never trust client progression. Browser terrain import is optional explicit conversion with a source backup, not automatic native save compatibility.

Export Windows x86_64 using matching 4.7.2 templates when separately authorized/available. Track export presets without signing secrets; verify clean-machine startup, writable `user://`, packaged resources/licenses, input/fullscreen, two local processes and upgrade/save paths. Choose portable archive versus installer and signing/distribution channel before release. Steam/relay/account integration, other OSes and public publishing are deferred. Forward+/D3D12/Jolt remain baseline; evaluate renderer fallback only on chosen hardware with visual/physics regressions.
